# Housing

This folder is reserved for the dash housing design files.

Planned contents:

- `source/` for editable CAD or parametric model files
- `stl/` for exported printable STL files

Initial housing assumptions:

- Screen module: Waveshare ESP32-S3-Touch-LCD-4.3B-BOX
- Board case outline from Waveshare: 116.3 mm x 79 mm
- Mounting target: removable dash pod or low-profile bracket
- Design constraints: serviceable USB-C access, ventilation, no windshield glare,
  and fused automotive accessory power routing
